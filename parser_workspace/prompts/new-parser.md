# New Parser Prompt

Используй этот промпт, когда нужно создать новый pyspider-парсер.

```text
Нужно создать pyspider-парсер для сайта: <SITE_URL>.

Работай по стандарту из parser_workspace/docs/parser-standard.md и используй шаблон parser_workspace/templates/pyspider_product_parser.py.

Требования:
- создать файл проекта в parser_workspace/examples/<donor>_project.py;
- сначала создать тестовый pyspider-проект <donor>_test;
- тестовый запуск: 3-5 карточек товара, без полного обхода каталога;
- не вставлять в код логины, пароли, прокси и приватные пути;
- секреты брать из env/config;
- собрать дерево категорий через save={"tree": [...]};
- скачать картинки и файлы к себе, а в результат сохранить локальные публичные пути;
- описание очистить от script/style/link-мусора;
- результат должен соответствовать parser-standard.md;
- после теста показать: task_status_count, result_count, 3 примера результата.

Порядок работы:
1. Изучи HTML стартовой категории, листинга и карточки товара.
2. Подбери селекторы.
3. Создай файл парсера.
4. Загрузи его в pyspider как <donor>_test.
5. Запусти тест на 3-5 карточках.
6. Исправь ошибки.
7. Останови тестовый проект после прогона.
8. Скажи, что готово для переноса в боевой проект <donor>.
```
