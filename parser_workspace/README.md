# Parser Workspace

Рабочая папка для разработки pyspider-парсеров.

## Структура

- `docs/parser-standard.md` - стандарт результата, обхода каталога и сохранения ассетов.
- `templates/pyspider_product_parser.py` - базовый шаблон товарного парсера.
- `prompts/new-parser.md` - промпт для создания нового парсера через Codex.
- `examples/` - тестовые или готовые проекты под конкретные сайты.

## Рекомендуемый процесс

1. Создать тестовый проект `<donor>_test`.
2. Запустить 3-5 карточек товара без полного обхода каталога.
3. Проверить результат в pyspider `resultdb`.
4. Включить одну категорию с пагинацией.
5. Только после проверки запускать полный проект `<donor>`.
